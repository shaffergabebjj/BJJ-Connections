About Gabe

The person behind BJJ Connections.

🥋

I'm Gabe Shaffer, a Brazilian Jiu-Jitsu practitioner who started training in 2025. I built BJJ Connections as a personal project to organize the techniques, resources, and tools I wish existed when I started — all in one place.

I'm interested in learning, competition, and helping other grapplers find useful information. This website is a work in progress, and I'm constantly adding new techniques, puzzles, and resources as I learn more.

The daily puzzle was the first thing I built — a Connections-style game where you find groups of four BJJ-related words. It's grown into a full resource with techniques, competition prep, training tools, and more.

Why I Built This

When I started BJJ, I found it hard to keep track of techniques, understand competition preparation, and find good resources in one place. BJJ Connections is my attempt to fix that — a simple, fast website that organizes useful BJJ information without unnecessary complexity.

The Project

BJJ Connections is a static website built with vanilla HTML, CSS, and JavaScript. It's open source and deployed through GitHub Pages. No backend, no tracking, no ads — just useful tools for grapplers.

The code is available on GitHub.

Disclaimer: BJJ Connections is a personal project, not affiliated with any academy, organization, or governing body. Technique descriptions are for educational reference only. Always train under qualified supervision.
