# BJJ Connections

A Connections-style puzzle game for Brazilian Jiu-Jitsu.

## Features
- Daily deterministic puzzle
- Training mode
- Four difficulty levels
- 50 preserved original puzzles
- Streaks and local statistics
- Persistent browser storage
- One Away feedback
- Learn Why explanations
- Share results
- Mobile-first layout
- Puzzle validation

## Files
- `index.html` — app structure
- `style.css` — responsive styling
- `data.js` — puzzle bank and validation
- `app.js` — gameplay, daily mode, stats, sharing

## Deployment
This remains compatible with GitHub Pages. Push these files to the repository root.
